## 12. 约束图为什么一定无环

key: acyclic / 章节4 / 视图acyclic-cards / 文字推导

当前播放文字：为什么约束图没有环？每条边都从"两行中都较早"指向"较晚"，所以按pos的顺序排下去，箭头永远指向前方——pos本身就是拓扑序。要出现环，得有某块"既在前面又在后面"，两个全排列做不到。有坐标就无环，无环才有最长路径。

画面短句：边总是从排列较早指向较晚：pos本身就是拓扑序

## 16. 27 与 36 说明什么

key: compare-reps / 章节6 / 视图compare-cards / 文字推导

当前播放文字：标准切片是27，标准B*-tree是27，标准序列对是36——这些只是"指定编码的解码结果"。要比较表示能力，得看编码空间能覆盖什么：这组固定五块、禁旋转的实例上，B*-tree 穷举5040棵树，最小包围盒24；序列对穷举14400个编码，最小也是24；切片却做不到——穷举26880份切片编码，最小只到25，一份24都没有。这两句证据要分开听：上一课结尾那张24布局确实一条第一刀都没有，所以它自己写不成切片树；但"所有切片编码都到不了24"不是从这一个布局推出来的，而是上面这次完备穷举的结果。单个反例说明不了其余两万多份编码，这个结论也只针对本实例。

画面短句：指定编码的结果≠表示法的能力；切片穷举最小25，B*-tree与序列对能到24
