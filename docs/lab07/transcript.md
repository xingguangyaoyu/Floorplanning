## 7. 变差的候选：接受概率 exp(−ΔE/T)

key: probability / 章节3 / 视图prob-table / 既有语音

当前播放文字：（沿用旧稿，见build/lab07/provenance.json cuts）

后续自然口播草稿（未录音）：对变差的候选，接受概率是exp(−ΔE除以T)。注意这是概率，不是"成功概率"：掷的是u这个随机数，u小于p才接受。同一个ΔE、同一个u，温度越高p越大——更容易接受后退。

## 16. 温度治不了邻域不可达

key: reachability / 章节7 / 视图reach-cards / 文字推导

当前播放文字：还有一个容易混的问题：接受行为与可达性。低温让变差难以被接受，搜索走得慢；但如果邻域本身够不着某个区域，调温没用。教材里有个对照：把邻域限制成"只交换固定原点上已有的模块"，某些起点就永远到不了最优——本站的邻域是任意交换序列对元素，没有那种锁死。判断慢的原因前，先分清这两类。

画面短句：低温影响接受行为；邻域够不着的目标，调温无济于事
